# API Blueprint

> API Blueprint is a high-level API description language for web APIs, written in a
> Markdown-based syntax. It was created by Apiary and released under the MIT License.
> Alongside the format, the project operates a live, open parsing service at
> https://api.apiblueprint.org that parses API Blueprint and Swagger 2.0 into API
> Elements (Refract) and composes API Blueprint back out of API Elements.

Generated by API Evangelist on 2026-09-02 from all/api-blueprint/apis.yml and the
artifacts in this repository. API Blueprint does not publish an llms.txt of its own;
https://apiblueprint.org/llms.txt returned 404 when probed on 2026-09-02.

## API

- [Service root](https://api.apiblueprint.org/): `GET /` returns `application/hal+json` listing the affordances `parse` and `compose`.
- [Parse](https://api.apiblueprint.org/parser): `POST /parser` with `Content-Type: text/vnd.apiblueprint` (or `text/vnd.legacyblueprint`, `application/swagger+json`, `application/swagger+yaml`) and `Accept: application/vnd.refract.parse-result+json`. Returns 200 with an API Elements parse result; 415 on an unsupported input media type; 406 on an unsupported output media type; 422 with annotations when the document does not parse.
- [Compose](https://api.apiblueprint.org/composer): `POST /composer` with `Content-Type: application/vnd.refract+json` or `application/vnd.refract.parse-result+json`. Returns 200 `text/vnd.apiblueprint`; 415 on an unsupported content type or Refract version.
